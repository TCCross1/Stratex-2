# STRATEX-QUANT // RESIDENTIAL DIAGNOSTIC NETWORK
## VERSION: 1.0.0
## ARCHITECTURE: AGENTIC-ORCHESTRATED TELEMETRY SUITE

### OVERVIEW
Stratex-Quant is a high-fidelity, autonomous residential diagnostic platform. It integrates DJI Manifold hardware with a multi-agent AI suite to automate roofing estimates, thermal moisture analysis, and structural integrity reports.

### CORE COMPONENTS
* **CONTROL TOWER (core.py)**: Project Manager AI responsible for agent orchestration.
* **HARDWARE GATEWAY (fleet_telemetry.py)**: High-speed ingestion for DJI Manifold 3 telemetry.
* **MASTER PORTAL**: React-based glassmorphic executive and field ops interface.
